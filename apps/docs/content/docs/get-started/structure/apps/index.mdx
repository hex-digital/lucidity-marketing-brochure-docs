Lucidity.js has three apps, found under `apps/`.

Each app is self-contained and can be [deployed independently](./../../deploy/index.mdx).

## Web

The Web app holds the Next.js website, which is used to serve the public-facing website.

[Read more about the Web app](./web.mdx).

## Sanity

The Sanity app holds the Sanity Studio, which is used to manage the content for the website.

[Read more about the Sanity app](./sanity.mdx).

## Storybook

The Storybook app holds the Storybook component library, which is used to develop and test the components for the website.

[Read more about the Storybook app](./storybook.mdx).
